# Nightshift

A 2-seat sport UTV powered by a Harley-Davidson Revolution Max 975T engine, designed as a parametric 3D CAD model in Python (CadQuery).

**[View the interactive 3D model](https://claude.ai/artifact/8DcWtxZSyx7EMGrQfryrVj)**

## The build
- **Engine:** Revolution Max 975T (liquid-cooled V-twin, 90 hp stock), mounted using the donor bike's factory frame sections
- **Drive:** 6-speed, chain drive to a custom solid rear axle on a swingarm, electric reverse
- **Chassis:** 1.75 x .120 and 1.50 x .120 DOM tube frame and roll cage
- **Wheels/tires:** 32x10-15
- **Wheelbase / track:** 108.5 in / 64 in
- **Fuel:** pony keg tank with a Sportster EFI pump insert
- **Body:** carbon fiber panels

## Status
Concept layout. Next step: measure the real engine and factory mounts, lock in final parts, and generate the cut list and notch sheets to build the first one to print.
